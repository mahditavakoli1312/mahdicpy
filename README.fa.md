## mahdicpy چیست؟

`mahdicpy` یک لایهٔ هوشمند روی همان `scrcpy` داخل همین پوشه است. هیچ‌چیز از scrcpy حذف نشده، یعنی **هر گزینه‌ای که scrcpy می‌پذیرد، mahdicpy هم می‌پذیرد** و بی‌تغییر به آن می‌دهد. چیزهایی که اضافه شده:

| قابلیت | توضیح |
|---|---|
| 🧠 **تنظیم خودکار** | اتصال USB یا Wi-Fi را تشخیص می‌دهد و کیفیت را متناسب با آن تنظیم می‌کند. نام گوشی روی پنجره نوشته می‌شود |
| 🎮 **۱۲ حالت آماده** | بازی، کیفیت بالا، اینترنت ضعیف، ارائه، صفحهٔ خاموش، دسکتاپ مجازی، دوربین، میکروفون و… |
| 📶 **Wi-Fi با یک دستور** | `mahdicpy wifi` گوشی را بی‌سیم می‌کند و آخرین گوشی را به خاطر می‌سپارد |
| 🔗 **جفت‌سازی بی‌سیم** | برای اندروید ۱۱ به بالا بدون نیاز به کابل |
| 🔁 **اتصال مجدد خودکار** | با `--watch` اگر اتصال قطع شود، خودش دوباره وصل می‌شود |
| 🎬 **ضبط هوشمند** | فایل با نام گوشی و تاریخ ذخیره می‌شود و خروجی GIF هم می‌گیرد |
| 📱 **اپ در پنجرهٔ جدا** | هر اپ را با اسمش در یک نمایشگر مجازی جدا باز می‌کند |
| 🧩 **چند گوشی** | همهٔ گوشی‌های وصل‌شده را کنار هم و به‌صورت شبکه‌ای روی صفحه می‌چیند |
| 📸 **اسکرین‌شات** | عکس را ذخیره می‌کند و مستقیم در کلیپ‌بورد مک می‌گذارد |
| 📊 **داشبورد گوشی** | باتری، دما، حافظه، RAM، رزولوشن و IP |
| 💾 **پروفایل** | مجموعه‌تنظیمات دلخواه را ذخیره و با `@اسم` اجرا می‌کند |
| 🩺 **doctor** | کل تنظیمات را بررسی می‌کند و مشکل را نشان می‌دهد |
| 🎨 **آیکون اختصاصی** | پنجرهٔ mahdicpy آیکون خودش را دارد |
| 🌐 **پنل وب** | نمایش و کنترل گوشی داخل مرورگر، اشتراک با تیم، به‌همراه ابزارهای توسعه‌دهنده |

**پیش‌نیاز:** مک و Python 3.8 یا بالاتر (روی مک معمولاً نصب است). `adb` و `scrcpy` داخل همین پوشه هستند و نیازی به نصب جداگانه ندارند. نصب `ffmpeg` فقط برای ساخت GIF لازم است و اختیاری است.

## نصب

```bash
git clone https://github.com/mahditavakoli1312/mahdicpy.git
cd mahdicpy
./install.sh             # نسخهٔ رسمی scrcpy (به‌همراه adb) را دانلود و بررسی می‌کند، سپس دستور mahdicpy را نصب می‌کند
mahdicpy doctor          # بررسی سلامت نصب
```

- `install.sh` نسخهٔ رسمی **scrcpy 3.3.4** را از گیت‌هاب Genymobile دانلود می‌کند، SHA-256 آن را بررسی می‌کند و در پوشهٔ `vendor/` قرار می‌دهد.
- اگر scrcpy را قبلاً با `brew install scrcpy` یا مدیر بستهٔ لینوکس نصب کرده‌اید، mahdicpy همان را پیدا می‌کند و نیازی به `install.sh` نیست.
- اگر ساخت لینک در `/usr/local/bin` خطای دسترسی داد، دستوری که چاپ می‌کند را با `sudo` اجرا کنید.

> اگر macOS موقع اولین اجرا به `scrcpy` یا `adb` اجازه نداد: **System Settings › Privacy & Security › Allow Anyway**

### آماده کردن گوشی (فقط یک بار)

1. **Settings › About phone** → هفت بار روی **Build number** بزنید.
2. **Settings › Developer options** → گزینهٔ **USB debugging** را روشن کنید.
3. گوشی را با کابل وصل کنید و پیام **Allow USB debugging** را تأیید کنید.
4. در گوشی‌های شیائومی گزینهٔ **USB debugging (Security settings)** را هم روشن کنید.

## افزودن میانبر

دو میانبر با آیکون mahdicpy ساخته می‌شود:

- **mahdicpy**: صفحهٔ گوشی را در یک پنجرهٔ جدا نشان می‌دهد.
- **mahdicpy Panel**: پنل وب را اجرا می‌کند و در مرورگر باز می‌کند. اگر پنل از قبل در حال اجرا باشد، فقط مرورگر را دوباره باز می‌کند.

`./install.sh` این میانبرها را خودش می‌سازد. برای ساختن آن‌ها به‌صورت دستی، مراحل سیستم‌عامل خودتان را دنبال کنید.

### 🍎 مک

1. **Terminal** را باز کنید و وارد پوشهٔ mahdicpy شوید: `cd mahdicpy`
2. این دستور را اجرا کنید:
   ```bash
   ./mahdicpy shortcut             # یا بعد از mahdicpy link فقط: mahdicpy shortcut
   ./mahdicpy shortcut --desktop   # اختیاری: آیکون روی دسکتاپ هم ساخته می‌شود
   ```
3. **mahdicpy** یا **mahdicpy Panel** را از **Launchpad**، **Spotlight** (⌘ Space) یا پوشهٔ `~/Applications` باز کنید.
4. اختیاری: آن‌ها را به **Dock** بکشید.

> اگر macOS بار اول اجازهٔ اجرا نداد: **System Settings › Privacy & Security** و بعد **Open Anyway**.

### 🐧 لینوکس

1. ترمینال را داخل پوشهٔ mahdicpy باز کنید.
2. این دستور را اجرا کنید:
   ```bash
   ./mahdicpy shortcut             # میانبرها را به منوی برنامه‌ها اضافه می‌کند
   ./mahdicpy shortcut --desktop   # اختیاری: آیکون روی دسکتاپ هم ساخته می‌شود
   ```
3. **mahdicpy** یا **mahdicpy Panel** را از منوی برنامه‌ها (Activities در GNOME یا منوی KDE) باز کنید.

> **mahdicpy Panel** داخل یک پنجرهٔ ترمینال باز می‌شود و با بستن آن پنجره، پنل متوقف می‌شود. اگر آیکون دسکتاپ باز نشد، روی آن کلیک راست کنید و **Allow Launching** را بزنید.

### 🪟 ویندوز

1. [Python 3](https://www.python.org/downloads/) را نصب کنید (گزینهٔ **Add python.exe to PATH** را تیک بزنید). [scrcpy ویندوز](https://github.com/Genymobile/scrcpy/releases) را هم دانلود کنید و `scrcpy.exe` و `adb.exe` را در `PATH` یا در پوشهٔ `vendor\` بگذارید.
2. **PowerShell** یا **Command Prompt** را داخل پوشهٔ mahdicpy باز کنید.
3. این دستور را اجرا کنید:
   ```powershell
   python mahdicpy shortcut             # میانبرها را به منوی Start اضافه می‌کند
   python mahdicpy shortcut --desktop   # اختیاری: آیکون روی دسکتاپ هم ساخته می‌شود
   ```
4. **mahdicpy** یا **mahdicpy Panel** را از **منوی Start** باز کنید. با کلیک راست و انتخاب **Pin to Start** یا **Pin to taskbar** می‌توانید آن‌ها را سنجاق کنید.

> **mahdicpy Panel** در یک پنجرهٔ کنسول باز می‌شود و با بستن آن پنجره، پنل متوقف می‌شود.

### حذف یا به‌روزرسانی میانبرها

```bash
mahdicpy shortcut --remove    # همهٔ میانبرها را حذف می‌کند (برای حذف آیکون‌های دسکتاپ، --desktop را هم اضافه کنید)
mahdicpy shortcut             # اگر پوشهٔ mahdicpy را جابه‌جا کردید، دوباره اجرا کنید
```

## شروع سریع

```bash
mahdicpy                 # نمایش صفحهٔ گوشی با تنظیم خودکار

mahdicpy wifi            # بی‌سیم شو (یک بار با کابل)

mahdicpy info            # داشبورد گوشی
mahdicpy help            # راهنمای کامل داخل ترمینال
```

## حالت‌ها (Modes)

```bash
mahdicpy <حالت> [گزینه‌ها]
```

| حالت | کاربرد | کاری که می‌کند |
|---|---|---|
| `mirror` *(پیش‌فرض)* | استفادهٔ روزمره | تنظیم خودکار برای USB یا Wi-Fi |
| `game` | بازی | ۱۲۰ فریم، بدون بافر، بیت‌ریت 16M، کیبورد فیزیکی (UHID) |
| `hq` | ضبط آموزش یا ارائه با کیفیت | بیت‌ریت 24M، صدای 256K |
| `low` | Wi-Fi ضعیف یا شبکهٔ شلوغ | 800px، بیت‌ریت 2M، ۳۰ فریم |
| `present` | جلسه و دمو | نمایش لمس‌ها، پنجره همیشه رو، گوشی خاموش نمی‌شود |
| `stealth` | صرفه‌جویی در باتری و حریم خصوصی | صفحهٔ گوشی خاموش می‌ماند ولی روی مک کار می‌کنید و موقع بستن، گوشی قفل می‌شود |
| `desktop [WxH/dpi]` | حالت شبیه دسکتاپ | نمایشگر مجازی جدا با رزولوشن 1920x1080 |
| `cam [front\|back]` | دوربین گوشی روی مک | پخش دوربین جلو یا عقب |
| `audio` | پخش صدای گوشی روی مک | فقط صدا، بدون پنجره |
| `mic` | گوشی به‌عنوان میکروفون | صدای میکروفون گوشی روی مک |
| `otg` | کنترل بدون adb | کیبورد و ماوس مک مثل کیبورد و ماوس واقعی گوشی عمل می‌کنند |
| `rec [--silent]` | ضبط | ضبط خودکار. با `--silent` بدون پنجره ضبط می‌کند |

مثال‌ها:

```bash
mahdicpy desktop 2560x1440/240      # دسکتاپ مجازی 2K
mahdicpy cam front                  # دوربین سلفی
mahdicpy game --max-fps=90          # گزینه‌های scrcpy هم قابل ترکیب‌اند
mahdicpy stealth -s 192.168.1.20    # گوشی مشخص با صفحهٔ خاموش
```

> **ترکیب گزینه‌ها:** ترتیب اعمال به این شکل است: تنظیم خودکار ← پیش‌فرض‌ها ← تنظیمات گوشی ← حالت ← پروفایل ← گزینه‌هایی که خودتان تایپ کرده‌اید. **هر چیزی که خودتان بنویسید، بقیه را بازنویسی می‌کند.**

## 🌐 پنل وب

```bash
mahdicpy web            # پنل را در مرورگر باز می‌کند (فقط روی همین مک)
mahdicpy web --lan      # اشتراک در شبکهٔ محلی با HTTPS، برای هم‌تیمی‌ها
```

پنل وب **مستقیم با scrcpy-server کار می‌کند** و تصویر H.264 را داخل خود مرورگر دیکد می‌کند (WebCodecs). یعنی:
- نیازی به نصب هیچ چیزی روی سیستم بیننده نیست و فقط یک مرورگر کافی است (Chrome، Edge، Safari 16.4+ یا Firefox 130+).
- تأخیر زیر ۱ میلی‌ثانیه روی شبکهٔ محلی است و تصویر تا ۶۰ فریم پخش می‌شود.
- چند نفر هم‌زمان یک گوشی را می‌بینند. برای هر گوشی فقط یک stream ساخته می‌شود و برای همه پخش می‌شود.

| 📜 **Logcat** | پخش زنده با رنگ‌بندی سطح لاگ، فیلتر متن، `tag:Name` یا `/regex/`، **فیلتر روی یک پکیج** (بر اساس PID)، توقف و ادامه، ذخیره در فایل و پاک کردن بافر دستگاه. **کرش و ANR خودکار تشخیص داده می‌شوند** و هشدار می‌دهند |
| 📦 **Apps** | جست‌وجوی پکیج‌ها، جزئیات (نسخه، minSdk و targetSdk، نصب‌کننده، debuggable)، اجرا، ری‌استارت، Force stop، **اندازه‌گیری Cold start** (با میانگین چند بار اجرا)، پاک کردن داده، حذف، دانلود APK، **روشن و خاموش کردن مجوزهای runtime** و نصب APK |
| 📁 **Files** | مرور فایل‌های گوشی، آپلود، دانلود، تغییر نام، حذف و ساخت پوشه، **پیش‌نمایش عکس، ویدیو و فایل متنی** |
| 🔍 **Inspector** | گرفتن ساختار UI (uiautomator)، درخت ویوها با جست‌وجو و **هایلایت المان‌ها روی تصویر زندهٔ گوشی**. با کلیک روی هر المان، **سلکتور تست آماده** برای **Espresso، UiAutomator، Compose، Appium XPath، Maestro و adb** ساخته و با یک کلیک کپی می‌شود |
| 🧪 **Dev toggles** | Layout bounds، Show taps، Pointer location، GPU overdraw، Profile GPU، **Don't keep activities**، **Force RTL** (برای تست فارسی)، Stay awake، Dark mode، **Demo mode** (نوار وضعیت تمیز برای اسکرین‌شات استور)، سرعت انیمیشن (۰ برای تست UI)، اندازهٔ فونت و density |
| 🔌 **Network** | **adb reverse** با دکمه‌های آماده (Metro 8081، Vite 5173، Next 3000، Django، Flask، Flutter DevTools)، **adb forward** (مثلاً Chrome DevTools)، **تست Deep link** همراه با زمان باز شدن و تاریخچه، ارسال Broadcast |
| ⌨ **Shell** | ترمینال `adb shell` با تاریخچه (↑ و ↓)، دستورهای آماده، کد خروج و زمان اجرای هر دستور |

### اشتراک با تیم

```bash
mahdicpy web --lan
```

در خروجی دو لینک چاپ می‌شود:

| لینک | دسترسی |
|---|---|
| 🔑 **Full access** | کنترل کامل و همهٔ ابزارها، از جمله shell و فایل‌ها. **فقط به افراد مورد اعتماد بدهید** |
| 👁 **View-only** | فقط تماشای صفحه و مشخصات دستگاه. هیچ کنترل یا ابزاری در دسترس نیست و برای ارائه یا دمو امن است |

- این دو لینک در ستون سمت چپ پنل هم با یک کلیک کپی می‌شوند.
- در حالت `--lan` یک گواهی HTTPS خودامضا ساخته می‌شود (مرورگرها برای پخش ویدیو به HTTPS نیاز دارند). بار اول مرورگر هشدار می‌دهد و باید **Advanced › Proceed** را بزنید.
- `--http` حالت HTTP ساده است. در این حالت روی دستگاه‌های دیگر فقط **Snapshot mode** با چند فریم در ثانیه کار می‌کند.
- لینک‌ها بین اجراها ثابت می‌مانند. برای باطل کردن همهٔ لینک‌های قبلی: `mahdicpy web --new-tokens`

### گزینه‌ها

| گزینه | کار |
|---|---|
| `--port 9000` | پورت دلخواه (پیش‌فرض 8765) |
| `--lan` | اشتراک در شبکهٔ محلی با HTTPS |
| `--http` | همراه با `--lan`: بدون HTTPS |
| `--token XYZ` | توکن ثابت برای دسترسی کامل |
| `--new-tokens` | ساخت توکن‌های جدید |
| `--no-open` | مرورگر را خودکار باز نکند |

### امنیت

- به‌صورت پیش‌فرض پنل فقط روی `127.0.0.1` در دسترس است.
- همهٔ درخواست‌ها به توکن نیاز دارند، پس سایت‌های دیگری که در مرورگر باز کرده‌اید نمی‌توانند به پنل دسترسی پیدا کنند.
- لینک Full access یعنی دسترسی `adb shell` به گوشی. آن را در گروه‌های عمومی منتشر نکنید.
- توکن‌ها و گواهی در `~/.config/mahdicpy/` ذخیره می‌شوند.

## اتصال بی‌سیم (Wi-Fi)

### روش ۱: با کابل (همهٔ نسخه‌های اندروید)

```bash
mahdicpy wifi
```

گوشی را با کابل وصل کنید و دستور بالا را بزنید. mahdicpy آدرس IP گوشی را پیدا می‌کند، حالت بی‌سیم را روشن می‌کند و وصل می‌شود. بعد از آن کابل را جدا کنید.
IP گوشی ذخیره می‌شود، پس دفعهٔ بعد **بدون کابل** همان `mahdicpy wifi` یا حتی فقط `mahdicpy` کافی است.

```bash
mahdicpy wifi 192.168.1.20          # اتصال مستقیم با IP
mahdicpy -s 192.168.1.20 game       # هر حالتی با IP
mahdicpy disconnect                 # قطع همهٔ اتصال‌های بی‌سیم
```

> بعد از ری‌استارت گوشی، حالت بی‌سیم خاموش می‌شود و باید یک بار دیگر با کابل `mahdicpy wifi` را بزنید.

### روش ۲: بدون کابل (اندروید ۱۱ به بالا)

1. در گوشی: **Developer options › Wireless debugging** را روشن کنید و **Pair device with pairing code** را بزنید.
2. در مک:

```bash
mahdicpy pair
# یا مستقیم:
mahdicpy pair 192.168.1.20:37099 482913
```

mahdicpy جفت‌سازی را انجام می‌دهد و پورت اتصال را هم خودش پیدا می‌کند.

## ضبط ویدیو و GIF

mahdicpy rec                        # نمایش + ضبط در ~/Movies/mahdicpy/

برای ساخت GIF اول `ffmpeg` را نصب کنید: `brew install ffmpeg`

## پروفایل‌ها

هر مجموعه از گزینه‌های scrcpy را می‌توانید با یک اسم ذخیره کنید:

```bash
# ساخت پروفایل
mahdicpy profile save work --max-size=1280 --always-on-top --window-x=0 --window-y=0
mahdicpy profile save night --turn-screen-off --max-fps=30

# استفاده (@ یا --profile)
mahdicpy @work
mahdicpy game @night --rec           # ترکیب حالت، پروفایل و ضبط

# مدیریت
mahdicpy profile list
mahdicpy profile rm night
```

### پیش‌فرض سراسری و تنظیمات هر گوشی

```bash
mahdicpy profile defaults --no-audio --shortcut-mod=rcmd   # روی همهٔ اجراها اعمال می‌شود
mahdicpy profile defaults                                  # پاک کردن پیش‌فرض‌ها
mahdicpy profile device --max-size=1024                    # فقط برای گوشی انتخاب‌شده
mahdicpy profile path                                      # محل فایل تنظیمات
```

همهٔ تنظیمات در فایل `~/.config/mahdicpy/config.json` ذخیره می‌شوند و این فایل را دستی هم می‌توانید ویرایش کنید.

## گزینه‌های سراسری

این گزینه‌ها را می‌توانید با هر حالتی و در هر جای دستور استفاده کنید:

| گزینه | کار |
|---|---|
| `-s <serial یا IP>` | انتخاب گوشی. اگر IP بدهید، به‌صورت بی‌سیم وصل می‌شود |
| `--rec` / `--rec=file.mp4` | ضبط |
| `--gif` | ضبط و ساخت GIF |
| `--silent` | همراه با ضبط: بدون پنجره |
| `--watch` | اتصال مجدد خودکار بعد از قطعی (کابل شل، قطعی Wi-Fi) |
| `@name` / `--profile name` | اعمال پروفایل |
| `--no-smart` | غیرفعال کردن تنظیم خودکار |
| `--dry-run` | فقط دستور نهایی scrcpy را نشان می‌دهد و اجرا نمی‌کند |
| هر گزینهٔ دیگر | مستقیم به scrcpy داده می‌شود (فهرست کامل: `./scrcpy --help`) |

```bash
mahdicpy game --watch --rec          # بازی + ضبط + اتصال مجدد
mahdicpy hq --dry-run                # دیدن دستور نهایی
```

## عیب‌یابی

| مشکل | راه‌حل |
|---|---|
| `no device found` | کابل دیتا (نه فقط شارژ) استفاده کنید و USB debugging را روشن کنید. بعد `mahdicpy doctor` را بزنید |
| `unauthorized` | قفل گوشی را باز کنید و پیام **Allow USB debugging** را تأیید کنید |
| `offline` یا گیر کرده | `mahdicpy restart-adb` |
| تصویر روی Wi-Fi کند است | `mahdicpy low` یا `mahdicpy -m 1024 -b 4M` |
| کلیک و تایپ در شیائومی کار نمی‌کند | گزینهٔ **USB debugging (Security settings)** را روشن کنید |
| کیبورد در حالت `game` کار نمی‌کند | کیبورد فیزیکی را در تنظیمات گوشی تأیید کنید یا بزنید: `mahdicpy game --keyboard=sdk` |
| اسکرین‌شات سیاه است | اپ‌هایی مثل اپ‌های بانکی جلوی عکس گرفتن را می‌گیرند |
| `--gif` کار نمی‌کند | `brew install ffmpeg` |
| نمی‌دانید دقیقاً چه دستوری اجرا می‌شود | `--dry-run` اضافه کنید |
| لاگ بیشتر لازم دارید | `mahdicpy -V debug` |
| پنل وب روی دستگاه دیگر فقط عکس ثابت نشان می‌دهد | از `--lan` بدون `--http` استفاده کنید، چون ویدیو فقط روی HTTPS یا localhost پخش می‌شود |
| پنل وب «unauthorized» نشان می‌دهد | لینک کامل چاپ‌شده در ترمینال را باز کنید، چون توکن داخل لینک است |
| Inspector خطای «UI dump failed» می‌دهد | صفحه در حال انیمیشن بوده. یک لحظه صبر کنید و دوباره Capture را بزنید |
